# Boundary asset

Source: the team’s local ABS STE_2021_AUST_GDA2020 shapefile, Australian Statistical Geography Standard Edition 3 (2021).
Original CRS: GDA2020 / EPSG:7844, longitude/latitude degrees. Display uses D3 Mercator; not for measurement.
The web asset retains the eight states/territories used in the hospitalisation comparison. Other territories and non-spatial records are excluded. Small coastal rings were omitted and long rings sampled to reduce file size. It is a simplified display asset, not an authoritative boundary dataset.
No hospitalisation data is included. Consult the original ABS metadata for licence and attribution before publication.
